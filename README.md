# Лабораторная работа №5: Взаимодействие с UI и состоянием. Тесты

## Цель работы
Изучить варианты взаимодействия пользователя с интерфейсом, механизмы сохранения состояния (State Hoisting, remember, mutableStateOf) и основы тестирования (Unit и UI тесты) в Jetpack Compose.

## Реализованные приложения

### 1. Tip Time (Калькулятор чаевых)
Приложение для расчета суммы чаевых на основе введенного счета и процента.
* Реализованы поля ввода с использованием `TextField`, настроена цифровая клавиатура (`KeyboardOptions`).
* Реализован переключатель (`Switch`) для округления суммы в большую сторону.
* Применен паттерн "поднятие состояния" (State Hoisting): логика хранения состояния вынесена в родительский компонент `TipTimeLayout`, а `EditNumberField` сделан компонентом без состояния.
* Использованы функции `remember` и `mutableStateOf` для предотвращения сброса состояния при рекомпозиции.
* Строки и цвета вынесены в ресурсы (`strings.xml`).

### 2. ArtSpaceApp (Галерея)
Приложение для просмотра картинок с переключением.
* Реализована навигация между тремя изображениями с помощью кнопок Previous и Next.
* Использована конструкция `when` для обновления текстовых данных (название картины, автор, год).
* Обеспечена поддержка широкого формата экрана: при повороте устройства (Landscape) интерфейс перестраивается из `Column` в `Row` с помощью `LocalConfiguration`.

## Тестирование
В приложении Tip Time реализованы тесты:
* **Unit-тест** (`TipCalculatorTests`): проверяет правильность логики функции `calculateTip()` без запуска эмулятора.
* **UI-тест** (`TipUITests`): имитирует ввод пользователя в текстовые поля и проверяет корректность отображения рассчитанной суммы на экране.

## Стек технологий
* Kotlin
* Jetpack Compose (Material 3)
* JUnit 4 (для Unit-тестов)
* Compose Test (для UI-тестов)
